 ----Space Shooter----

-> About
This game is based off of the classical space shooter game.
^ is the main ship and it is being attack by multiple enemy ships.
Your goal is to dodge and enemy ships and shoot them if they get in your way.

-> Controls
A -> Move the space ship left
D -> Move the space ship right
Space -> Shoot

-> Features
1. There is a menu to this game.
2. There is a score counter.
